# RAG-A2Z
A comprehensive repository covering end-to-end implementations of Retrieval-Augmented Generation (RAG) techniques from foundational pipelines to advanced paradigms like Agentic RAG, HyDE, GraphRAG, Self-RAG, and Adaptive RAG. Built with a focus on practical understanding, modular design, and real-world applicability.

##### From APIs to First-Principles RAG Systems
A deep, systematic exploration of Retrieval-Augmented Generation (RAG) — implementing every major technique twice:
(1) using modern frameworks/APIs and
(2) rebuilding from scratch to understand the underlying mechanics.

### Objectives

Understand the core mechanics of RAG systems
Compare different RAG paradigms in real scenarios
Analyze trade-offs (latency, accuracy, cost, complexity)
Build modular, extensible pipelines
Develop intuition for when to use which RAG technique

### Motivation 

Most RAG tutorials today abstract away the hardest parts using tools like managed APIs and orchestration frameworks.
While this accelerates development, it often hides how RAG systems actually work under the hood.

### Techniques to be covered

Vanilla RAG
HyDE
Self RAG
Agentic RAG
GraphRAG
CRAG
Adaptive RAG
